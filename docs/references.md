# Official product references

Use these official Webex resources when you adapt the lab pattern. The lab instructions remain the authority for the temporary sandbox, Order Desk simulation, supplied credentials, and event-specific UI path.

## Architecture and MCP

- [AI in Webex](https://developer.webex.com/mcp/docs/ai-in-webex) — how a Webex AI agent uses an external MCP server to reach a business system.
- [Agentic Apps overview](https://developer.webex.com/mcp/docs/agentic-apps-overview) — the Agentic App model and MCP-based tools.
- [MCP security overview](https://developer.webex.com/mcp/docs/security-overview) — security boundaries and practices for MCP integrations.

## Administration and agent configuration

- [Onboard your MCP server](https://developer.webex.com/mcp/docs/onboard-your-mcp-server) — register the external server as a Developer Portal Agentic App.
- [Provision Agentic Apps in Control Hub](https://developer.webex.com/mcp/docs/provisioning-on-control-hub) — allow the app, configure Custom Headers, and enable `lookup_order`.
- [Configure MCP actions in AI Agent Studio](https://developer.webex.com/mcp/docs/mcp-ai-agent-studio) — select the approved MCP tool for an autonomous agent.
- [AI Agent Studio administration](https://help.webex.com/default/article/ncs9r37) — configure, add actions to, preview, and publish an AI agent.
- [Use AI agent templates](https://help.webex.com/article/n8mo4c) — create an agent from a built-in template.

## Flow Designer

- [Build and manage flows with Flow Designer](https://help.webex.com/article/nhovcy4) — Flow Designer activities, validation, and publishing.
- [Flow Orchestration API guide](https://developer.webex.com/webex-contact-center/docs/api/guides/flow-orchestration) — the FlowV2 document and validation contract behind programmatic flow authoring.

## Bonus: Webex Contact Center MCP services

- [Contact Center MCP Server](https://developer.webex.com/mcp/docs/contact-center-mcp-server) — the Webex Contact Center server with Flow Designer search, read, draft, activity-discovery, and validation tools. Its Flow tools work with FlowV2. The server page provides the regional URL after sign-in; the organization must enable the app and the individual tools.
- [Contact Center MCP Server beta getting-started guide](https://developer.webex.com/create/docs/contact-center-mcp-server-beta) — connection, read-first checks, and a bounded unpublished draft exercise. Use the beta instructions only in a tenant enabled for this program.
- [Contact Center Operation MCP Server beta getting-started guide](https://developer.webex.com/create/docs/contact-center-operation-mcp-server-beta) — a separate, read-only server for configuration, routing, reporting, contact, and AI Agent operational questions. It cannot create, update, publish, or delete flows.

Product interfaces evolve. If a label has changed, preserve the outcome described by the checkpoint and consult the corresponding official reference.
