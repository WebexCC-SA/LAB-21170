# Checkpoint 1: Open the lab and redeem your assignment

1. Open [MCP Lab](https://mcp-lab.webexdevs.com/).
2. Enter the lab token supplied by the facilitator.
3. Select **Continue**.
4. Confirm that MCP Lab opens **Inspect an MCP** for your assigned exercise.
5. Open **Test tenant details**.
6. Keep this panel available. You will use the sandbox sign-in details, assignment expiration, Order Desk REST address, Order Desk MCP address, temporary bearer token, and sample order number in later checkpoints.

## Useful links and bookmarks

| Workspace | Link | Use it for |
| --- | --- | --- |
| Collaboration Control Hub | [admin.webex.com](https://admin.webex.com/) | Sign in to the assigned organization, check the entry point and queue, and open Contact Center tools. |
| Flow Designer | [flow-control.produs1.ciscoccservice.com](https://flow-control.produs1.ciscoccservice.com/) | Open the Flow Designer canvas for this lab's ProdUS1 environment. You can also launch it from Control Hub. |
| AI Agent Studio | [Launch from Control Hub](https://admin.webex.com/) | Open **Contact Center → Customer Experience → AI Agents**; Control Hub opens the studio in a new tab. |
| Webex Developer Portal | [developer.webex.com](https://developer.webex.com/) | Register the external MCP as an Agentic App. This site provides developer access and documentation, not the Flow Designer canvas. |
| MCP Lab | [mcp-lab.webexdevs.com](https://mcp-lab.webexdevs.com/) | Inspect your assigned tenant details and Order Desk tools. |

If a direct link opens a different region or organization, use the destination shown by your assigned sandbox and launch the tool from Control Hub.
